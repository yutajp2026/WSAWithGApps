# Windows Subsystem for Android with GApps

[日本語版に移動](/README.md)

> [!WARNING]
> The [WSA](https://learn.microsoft.com/en-us/previous-versions/windows/android/wsa/) itself was discontinued on March 5, 2025.


A version of WSA with Google Apps, built using [MagiskOnWSALocal](https://github.com/LSPosed/MagiskOnWSALocal).  
Also supports English.
# Recommended Software

## [WSA_Pacman](https://github.com/alesimula/wsa_pacman)
An APK installer for WSA.
> [!CAUTION]
> You must enable Developer mode from the **WSA app screen** to install APKs.
